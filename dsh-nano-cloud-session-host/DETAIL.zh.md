# 云端会话原生宿主

[dsh-nano-cloud-session] 的宿主 overlay 伴生包。官方 [dsh] 当前版本还没有外部会话的原生视图；本包用同版本上游加一份补丁构建出的宿主与浏览器模块，替换原版的会话、终端、工作区文件、对话与右侧工作台行，让云端会话以原生 Chat 和工作台打开。

## 它做什么

- 宿主声明 `sessionController.externalSessions`（视图版本 1），云端会话插件据此把会话映射成原生外部会话。
- 外部会话的消息以原生 user/assistant 样式渲染；文件、附件、终端 tab 按会话能力过滤。
- 文件与终端只对授权文件中列出的会话开放，授权只能由操作者在本机写入。

## 卸载

从已安装插件中移除本包并重启宿主，八个原版行恢复，云端会话插件回到「原生视图不可用」状态。
