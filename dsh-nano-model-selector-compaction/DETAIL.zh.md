# 异步压缩接管

[dsh-nano-model-selector] 的宿主侧互斥扩展。启用后，四个 agent preset（standard / ptc / minimal / cordis）的 `id:compaction` 组改挂异步压缩引擎，原厂 `compaction-basic` 行停用。关闭后 patch 层撤掉，原厂压缩回来。模型选择器本体始终保留。

**安装 ≠ 接管。** 本包出现在已安装插件列表里，只表示可以接管；开关在模型选择器里，默认应保持关闭。

## 在哪里管理

打开 composer 的模型选择器。顶栏搜索框与关闭按钮之间的「异步压缩」按钮进入管理页。**只有本插件已安装时这个按钮才出现**；未安装时搜索框会占满该位。目录刷新在搜索框内部。

管理页可做：

- 切换接管开关（唯一写入口）。生效后可能要求重启宿主，页面会写明。
- 选摘要模型（flash 家族，选项标注 provider、模型名与锚定上下文窗口）。
- 调缓冲水位 B、健康水位 H、异步保留 tokens。安全水位 S（0.90）只读。H 可以等于 B，B 可以等于 S。
- H 必须低于 B，B 必须低于 S；违反时保存被拒绝，值不写盘。
- 「压缩说明」按常态 / 触线 / 安全线 / 降级四个场景，用当前水位与模型插值说明实际行为。

## 启用后发生什么

填充低于 B 不压缩。达到 B 后，旧段交给摘要模型异步摘要，直到回落到 H；最近一段 tokens 保持原文。填充继续涨到 S 而异步来不及时，全量直压兜底。状态文件不可读或计量不可用时，只有 S 生效。
